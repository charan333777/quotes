## ✨ Overview

A clean, no-framework **random quote generator** — click a button and get a fresh quote, with a responsive UI that works on any screen. Built purely with **vanilla JavaScript, HTML and CSS** to keep it fast and dependency-free, and a nice little exercise in DOM manipulation and front-end fundamentals.

## 🧩 Features

- 🎲 **Random quotes** — generates a new quote on demand
- 🎨 **Clean, responsive UI** — styled with plain CSS, looks good on mobile and desktop
- ⚡ **Zero dependencies** — no frameworks or build step, just open and run
- 🧠 **Fundamentals-first** — a focused demo of DOM manipulation and event handling

## 🛠️ Tech Stack

| Layer | Technology |
| --- | --- |
| Structure | HTML5 |
| Styling | CSS3 |
| Logic | Vanilla JavaScript |

## 💻 Getting Started

No build tools required — just clone and open in your browser:

```bash
git clone https://github.com/charan333777/quotes.git
cd quotes
```

Then open `index.html` in your browser (or serve the folder with any static server).
